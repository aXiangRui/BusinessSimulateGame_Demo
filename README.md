**模拟经营甜品店游戏尝试**
本项目是基于SDL2图形库所制作的2D模拟经营类游戏，支持实现甜品制作、产品上架及顾客的购物流程

##功能简介
    - 甜品合成：在合成界面可以基于蛋糕胚及材料进行合成，在符合合成配方后会产生全新产品
    - 甜点摆放：将当前已有的蛋糕放置到面包柜中，供人们选择
    - 顾客拜访：顾客基于购买的甜品种类及数量增加好感值，在好感值达到临界值时，会为商店带来礼物：新的材料 || 新的蛋糕胚 || 新顾客

##配置需要
    内容:[MinGW](https://www.mingw-w64.org/)、[SDL2](https://www.libsdl.org/)
当然，由于项目的exe文件已经静态链接上述配置内容，如果直接打开exe文件是无需上述配置的，但是针对源文件的读取与运行建议完成上述配置，然后在vscode中运行start.cpp文件
