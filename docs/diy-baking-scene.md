# DIY 烘焙场景设计方案

> 整合：经典合成与自由DIY双模式、切分层、夹心、浸液糖浆、抹面、裱花、调色、形状、尺寸层级、顶部装饰布局、隐藏流心、品质系统、厨师技能

---

## 1. 核心设计：双模式并行

进入制作场景时，玩家先做选择：

```
进入制作
    ↓
┌──┴──┐
↓     ↓
经典   自由DIY
合成   (14阶段创作)
↓     ↓
快速补货   精品创作
```

### 经典合成

- **定位：** 快捷补货通道
- **流程：** 选盘 → 选基类 → 选材料(3种) → 选装饰(3种) → 出品
- **品质：** 固定为 **Good**（×1.0 价格系数）
- **属性：** 预设固定值，不参与烘焙/切片/夹心等系统
- **作用：** 早上开店发现货架空了的救急方案，20秒做一单
- **产出物品：** 与现有系统一致，产出预设甜品（草莓蛋糕等）

### 自由DIY

- **定位：** 精品创作通道
- **流程：** 14阶段完整流程
- **品质：** 浮动 Overdone ~ Perfect（×0.7 ~ ×1.5 价格系数）
- **属性：** 由所有阶段的选择叠加计算得出
- **作用：** 独一无二的创作体验
- **产出物品：** DIYProduct，拥有自定义名称和完整数据

## 2. 定价公平性规则

原则：**不靠硬砍经典合成的价格来体现DIY的价值，而是让DIY因为更高的属性投入和操作水平自然卖出高价。**

| 维度 | 经典合成 | 自由DIY |
|------|---------|---------|
| 品质 | 固定 Good（×1.0） | 浮动（×0.7 ~ ×1.5） |
| 属性来源 | 预设固定值 | 基底 + 风味 + 夹心 + 糖浆 + 品质 叠加计算 |
| 材料消耗 | 3种材料 + 1基类 | 3种风味 + N种夹心 + 抹面 + 装饰 + 1基类 |
| 耗时 | ~20秒 | 2~5分钟 |
| 价格下限 | 稳定（确定能卖） | 可能低于经典（烤焦/夹生 → ×0.7） |
| 价格上限 | 固定 | 远高于经典（完美三层 → ×1.5 + 层级加成） |

**玩家直觉对比示例：**

```
经典合成草莓蛋糕
  属性：甜30 饱30 口感30
  价格：18 💰

DIY 戚风草莓夹心蛋糕（一般烘焙）
  属性：甜35 饱25 口感32
  品质：Acceptable（×1.0）
  价格：≈ 20 💰（略高于经典）

DIY 戚风草莓夹心蛋糕（完美烘焙）
  属性：甜35 饱25 口感32 + 夹心加成 + 糖浆加成
  品质：Perfect（×1.5）
  价格：≈ 40+ 💰（远高于经典）
```

核心结论：**经典合成靠的是稳定省心，DIY靠的是上限高。两者不打架。**

## 3. 配方发现机制

**连接双模式的桥梁：**

当你在自由DIY中做出的组合刚好匹配某个经典配方时：

```
你做了一款戚风蛋糕+草莓+奶油
      ↓
系统检测到匹配"草莓蛋糕"配方
      ↓
┌──────────────────────────┐
│ 🎉 发现经典配方！          │
│                          │
│ 「草莓蛋糕」已收录至配方图鉴  │
│                          │
│ 以后可在经典合成中一键制作   │
│                          │
│        [ 确认 ]           │
└──────────────────────────┘
```

**配方发现的好处：**
- 鼓励玩家在DIY中反复尝试不同组合
- 每发现一个新配方，经典合成里就多一个快捷选项
- 图鉴系统 = 收集驱动力
- 发现的配方越多，补货越方便

## 4. 自由DIY完整流程

```
选形状 ─┬─ 圆形（默认）
        ├─ 方形（默认）
        ├─ 心形（厨师 Lv3）
        ├─ 星形（特殊解锁）
        └─ 花形（节日/后期）
   ↓
选基类蛋糕（已解锁的基类甜品）
   ↓
选尺寸层级 ─┬─ 单层（默认）
            ├─ 双层（厨师 Lv5）
            └─ 三层（厨师 Lv8+）
   ↓
加风味材料（最多3种，同现有create流程）
   ↓
选浸液糖浆 ─┬─ 无 / 蜂蜜 / 朗姆酒（默认）
            ├─ 咖啡液 / 焦糖酱（厨师 Lv2/4）
            └─ 抹茶糖浆（对应材料解锁）
   ↓
🔥 烘焙 ──── 迷你控火游戏
   ├─ 三档温控：低/中/高
   ├─ 三条隐藏曲线：内部熟度/表面焦化/水分保留
   ├─ 玩家选时机"出炉"
   └─ 品质结果：夹生→烤焦→略过→一般→良好→完美
   ↓
切分蛋糕 ─┬─ 切2片（1层夹心）
           └─ 切3片（2层夹心）
   ↓
每层填夹心（每层从奶油/果酱/巧克力/特殊材料中选）
   ↓
外层抹面 + 选色（预设色板，厨师 Lv9 解锁自定义RGB）
   ↓
裱花纹路 + 选色（厨师等级逐级解锁新纹路）
   ↓
顶部装饰 + 布局模式（聚拢/环绕/散落/斜线）
   ↓
自定义命名
   ↓
成品预览
   ↓
确认出品 → 保存到存档 → 返回游戏
```

## 5. 各阶段说明

### 5.1 选形状

| 名称 | 解锁条件 | 说明 |
|------|---------|------|
| 圆形 | 默认 | 经典造型，适用所有场景 |
| 方形 | 默认 | 简约风格 |
| 心形 | 厨师 Lv3 | 适合特殊订单（生日/告白） |
| 星形 | 特殊解锁 | 节日限定潜力 |
| 花形 | 后期 | 高等级玩家追求 |

形状影响切片贴图的裁切区域，不影响核心属性，主要决定视觉风格。

### 5.2 选基类蛋糕

同现有逻辑，只显示已解锁的基类甜品（WhetherBase = true）。

基类ID影响：
- 烘焙参数（推荐温度、最佳时长、厚度系数）
- 基础风味属性（甜度/饱腹感/口感基底值）

### 5.3 选尺寸层级

| 层级 | 蛋糕用量 | 切片总数 | 夹心层总数 | 价格系数 | 解锁 |
|------|---------|---------|-----------|---------|------|
| 单层 | 1个蛋糕 | 2~3片 | 1~2层 | ×1.0 | 默认 |
| 双层 | 2个蛋糕 | 4~6片 | 2~4层 | ×2.2 | 厨师 Lv5 |
| 三层 | 3个蛋糕 | 6~9片 | 3~6层 | ×3.8 | 厨师 Lv8+ |

层级越高，烘焙难度越大（升温更慢，中心更难熟透）。

### 5.4 加风味材料

同现有 `Stage::create`，最多选3种材料（奶油/草莓/巧克力/水果等）。

### 5.5 选浸液糖浆

蛋糕切片后刷糖浆，增加湿润度和风味层次。

| 糖浆 | 解锁 | 属性影响 |
|------|------|---------|
| 无 | 默认 | 无 |
| 蜂蜜 | 默认 | +甜度 +口感 |
| 朗姆酒 | 默认 | +口感 -甜度 +香气 |
| 咖啡液 | 厨师 Lv2 | +口感 -甜度 |
| 抹茶糖浆 | 解锁抹茶材料 | +风味 +甜度 |
| 焦糖酱 | 厨师 Lv4 | +甜度 +香气 |

糖浆引入第四属性维度 **香气(aroma)**，影响顾客满意度。

### 5.6 🔥 烘焙小游戏

详见独立文档 `docs/baking-system.md`，核心要点：

- 玩家控制三档温度（低/中/高火）
- 三条隐藏曲线实时变化：内部熟度、表面焦化、水分保留
- 玩家选择"出炉"时机
- 品质判定：Raw / Burnt → 废品，Overdone / Acceptable / Good / Perfect 四个可售卖等级

品质对价格影响：

| 品质 | 价格系数 | 顾客满意度 |
|------|---------|-----------|
| Raw | ❌ 不可出售 | — |
| Burnt | ❌ 不可出售 | — |
| Overdone | ×0.7 | -20% |
| Acceptable | ×1.0 | 基准 |
| Good | ×1.25 | +15% |
| Perfect | ×1.5 | +30% |

层级越高烘焙越难：
- 双层：升温慢15%，时长+30%
- 三层：升温慢30%，时长+60%

### 5.7 切分蛋糕

| 切法 | 夹心层数 | 适合场景 |
|------|---------|---------|
| 切2片 | 1层夹心 | 简单直接，突出单一夹心风味 |
| 切3片 | 2层夹心 | 层次丰富，可组合两种不同夹心 |

### 5.8 每层填夹心

每层夹心从已解锁的材料中选择，可用材料包括奶油类、果酱类、巧克力类、特殊类。

**流心隐藏夹心（进阶）：** 特定组合触发流心效果（如草莓酱+奶油芝士、巧克力酱+朗姆酒糖浆），额外+价格系数 + 视觉特效。

### 5.9 外层抹面 + 调色

抹面材料选择 + 颜色自定义。

预设色板：
```
[⚪白] [⚫黑] [🔴红] [🟠橙] [🟡黄]
[🟢绿] [🔵蓝] [🟣紫] [🩷粉] [🤎棕]
```

厨师 Lv9 解锁自定义 RGB 调色（滑动条调色）。

### 5.10 裱花纹路 + 调色

裱花纹路绑定厨师等级，逐级解锁：

| 纹路 | 解锁条件 | 说明 |
|------|---------|------|
| 无裱花 | 默认 | 什么都不加 |
| 星形花嘴 | 默认 | 基础裱花 |
| 贝壳纹 | 厨师 Lv2 | 波浪形花纹 |
| 玫瑰挤花 | 厨师 Lv4 | 旋纹玫瑰花 |
| 网格裱花 | 厨师 Lv6 | 交叉网格装饰 |
| 蕾丝裱花 | 厨师 Lv8 | 精细花纹 |
| 多层花边 | 厨师 Lv10 | 华丽装饰 |

颜色同样支持预设色板 + Lv9 自定义RGB。

一副裱花贴图可用在所有蛋糕上（着色叠加），不需要为每种蛋糕各备一套。

### 5.11 顶部装饰 + 布局

最多放3种装饰材料，从已解锁的装饰材料中选择。

布局模式：

| 布局 | 效果 |
|------|------|
| 聚拢 | 所有装饰集中在蛋糕中心 |
| 环绕 | 沿蛋糕边缘均匀分布 |
| 散落 | 随机分布在表面 |
| 斜线 | 沿对角线排列 |

### 5.12 自定义命名

糖浆默认名（如"特制戚风蛋糕"），玩家可修改，最多15个汉字/30字符。

### 5.13 成品预览

展示所有阶段的最终效果——视觉渲染 + 属性面板 + 预计售价。

玩家可选择"返回修改"或"确认出品"。

## 6. 厨师技能体系

分两系成长：

| 等级 | 🍳 烘焙系 | 🎨 装饰系 |
|------|----------|----------|
| Lv1 | 基础烘焙（解锁烤箱） | 基础抹面 |
| Lv2 | 精准控温（容错+5%） | 贝壳裱花 |
| Lv3 | 心形模具解锁 | 双色抹面 |
| Lv4 | 烘焙直觉（容错+10%） | 玫瑰裱花 |
| Lv5 | 双层蛋糕解锁 | 散落布局解锁 |
| Lv6 | 高温耐受（高火容错+10%） | 网格裱花 |
| Lv7 | 三层蛋糕解锁 | 斜线布局解锁 |
| Lv8 | 完美之眼（Perfect+10%） | 蕾丝裱花 |
| Lv9 | 大师烘焙（容错+20%） | 自定义调色解锁 |
| Lv10 | 传奇烘焙师 | 传奇甜品师 |

经验获取：

| 行为 | 经验 |
|------|------|
| 完成一个DIY产品 | +10 烘焙 +10 装饰 |
| Good品质出品 | +15 烘焙 |
| Perfect品质出品 | +30 烘焙 |
| 顾客好评 | +5 烘焙 +5 装饰 |

厨师等级影响烘焙时的容错区间——等级越高，Perfect判定区间越宽。

## 7. 渲染架构

成品渲染从下到上分7层：

```
7. 品质光效（仅Perfect时闪烁）
6. 顶部装饰 × 布局模式
5. 裱花纹路（半透明 + 颜色着色）
4. 外层抹面（半透明 + 颜色着色）
3. 夹心层 × N
2. 蛋糕切片 × (tier × sliceCount)
1. 盘子
```

每增加一个DIY维度，影响对应的渲染层。货架上展示时可用简化渲染（主视觉+名称标签），无需每帧完整分层。

## 8. 存档

新增存档文件：`save/DIYProduct.rui`

记录每个DIY产品的全部阶段数据（基类、形状、层级、风味材料、糖浆、品质、切片数、夹心材料、抹面材料+颜色、裱花纹路+颜色、装饰+布局、自定义名称）。

经典合成的产品沿用现有 `save/Product.rui`，与DIY产品互不干扰。

## 9. 资源需求

需要的贴图资源（按类型）：

| 类别 | 数量 | 说明 |
|------|------|------|
| 蛋糕切片 | 每基类×形状 | 如 7基类×3形状 = 21张（可分批画） |
| 裱花纹路 | 6~7张 | 半透明花纹，通用在所有蛋糕上 |
| 抹面纹理 | 1张 | 纯白底纹 + 代码调色 |
| 形状图标 | 5个 | 圆/方/心/星/花 的UI图标 |
| 布局图标 | 4个 | 聚拢/环绕/散落/斜线 |
| 品质标记 | 6个 | 小标徽 |

**可先做再补的策略：**
- 第一阶段：纯代码画UI（SDL_RenderFillRect + TTF文字），0新贴图
- 第二阶段：补形状图标 + 品质标记 + 裱花纹路
- 第三阶段：补切片贴图 + 抹面纹理

## 10. 组合多样性

```
基类(7) × 形状(5) × 层级(3) × 风味(C22,3) × 
糖浆(6) × 品质(6) × 切法(2) × 夹心(5²~5⁶) ×
抹面(4) × 颜色(10) × 裱花(7) × 颜色(10) ×
装饰(C22,3) × 布局(5)

理论组合数 ≈ 10¹⁴，实际受解锁限制在数万级别。
```

价值不在于"理论上无限"，而在于**每个玩家做出来的蛋糕都不一样**，可以展示、分享、被顾客记住。

## 11. 边界情况处理

| 场景 | 处理 |
|------|------|
| 旧存档无DIY产品 | 跳过DIYProduct.rui读取，兼容 |
| 经典合成产品读取旧存档 | quality 默认 Acceptable |
| 玩家DIY中途退出 | 不保存任何临时数据 |
| 材料未解锁 | 列表中灰显 + 🔒标记 |
| 烤焦/夹生 | 提示废品，可选择重烤或放弃 |
| 厨师无烘焙等级 | 默认 Lv1 |
| 顾客购买DIY产品 | 货架显示简化渲染 + 名字标签 |
